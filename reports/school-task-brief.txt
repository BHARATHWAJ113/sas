# Codex Task: Implement Dynamic School Website Sections with Admin Panel Management

## Project Details

**Project:** St. Antony's Matriculation Higher Secondary School Website  
**Website:** https://stantonysneyveli.in  
**Local Asset Directory:** `D:\SAS\assets\schl_doc`

## Objective

Enhance the existing school website by implementing five fully dynamic sections with complete administrative management. Use the documents, images, and other relevant resources available in the specified local asset directory.

Follow the website's existing technology stack, coding standards, database architecture, and design system.

**Important:** Inspect the existing project structure, database schema, admin panel, and asset directory before implementing changes. Reuse existing components and functionality wherever possible. Do not create duplicate features.

## 1. Dynamic School Fees Structure

Implement a fully dynamic, standard-wise school fees management system.

**Frontend Requirements:**
- Display the fees structure based on the selected class or standard.
- Provide a dropdown to select standards from LKG to Class 12.
- Display applicable fee categories such as tuition fees, admission fees, term fees, and other charges.
- Show fee amounts, payment frequency, and total fees in a responsive table.
- Apply an elegant, professional, mobile-friendly design.
- Handle missing fee information gracefully.

**Admin Panel Requirements:**
- Add, edit, delete, and view fee records.
- Manage fees separately for each standard.
- Support academic year, fee category, amount, and payment frequency.
- Allow administrators to activate or deactivate fee records.
- Provide filtering and search functionality.

## 2. Roll of Honour

Create a professional and dynamic Roll of Honour section.

**Frontend Requirements:**
- Display student achievements in an attractive and organized layout.
- Include student name, achievement title, academic year, class, description, and photograph where available.
- Support academic-year filtering.
- Use a modern, elegant card-based design.
- Maintain the school's professional appearance.

**Admin Panel Requirements:**
- Add, edit, delete, and view honour records.
- Upload student photographs.
- Manage achievement categories, academic years, and display order.
- Enable or disable individual records.

## 3. Dynamic Staff Directory

Implement a complete staff directory with photographs.

**Frontend Requirements:**
- Display staff members in a responsive grid layout.
- Include staff photograph, name, designation, department, and other available relevant details.
- Categorize staff by department or staff type.
- Provide search and filtering options.
- If a staff photograph is unavailable, automatically display a professional default profile image.
- Maintain consistent image dimensions and alignment across all staff cards.

**Admin Panel Requirements:**
- Add, edit, delete, and view staff profiles.
- Upload, replace, and remove staff photographs.
- Manage staff categories, designations, departments, and display order.
- Enable or disable staff profiles.

## 4. Dynamic Academic Toppers Section

Create a visually attractive, modern, and professional academic toppers section.

**Frontend Requirements:**
- Display toppers with student photographs, names, standards, academic years, marks, percentages, and ranks where applicable.
- Include filters for academic year, standard, and examination category.
- Use elegant cards with subtle animations and hover effects.
- Highlight top performers appropriately without making the design overly colourful or distracting.
- Use smooth transitions, responsive layouts, and professional typography.
- Handle missing student photographs using a default image.

**Admin Panel Requirements:**
- Add, edit, delete, and view topper records.
- Upload student photographs.
- Manage academic years, standards, examination types, marks, percentages, and ranks.
- Support display ordering and active/inactive status.

## 5. Modern Dynamic Photo Gallery

Develop a fully dynamic school photo gallery with a clean, modern design.

**Frontend Requirements:**
- Display photographs using a responsive masonry or well-balanced grid layout.
- Organize photographs into categories such as school events, celebrations, academics, sports, cultural activities, and achievements, based on available content.
- Implement a modern image lightbox with zoom and navigation.
- Support lazy loading, image optimization, and responsive image sizes.
- Use subtle hover effects and smooth transitions.
- Maintain consistent visual quality across desktop, tablet, and mobile devices.

**Admin Panel Requirements:**
- Upload single or multiple photographs.
- Add image titles, descriptions, categories, and event dates.
- Edit, delete, reorder, and manage gallery photographs.
- Enable or disable photographs.
- Provide image previews before publishing.
- Validate uploaded file types and sizes.

`D:\SAS\assets\schl_doc`
